# Data

The data are not stored in this repository. Download the public use file from the Consumer Financial Protection Bureau:

- **File:** `NFWBS_PUF_2016_data.csv`
- **Source:** CFPB, National Financial Well-Being Survey, public use file and codebook (consumerfinance.gov)

Place the file in this folder, then run `code/01_build.do` from the repository root. The build creates `p04_analytic.dta` and `p04_analytic.csv` here.
